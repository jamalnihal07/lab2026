❓ FAQ

How do I run the application?

Simply open index.html in your browser, or use a local server (Python: python -m http.server 8000)

Is there a backend required?

No, the frontend is fully functional as a standalone application with simulated data.

Can I customize the styling?

Yes! Edit styles.css to change colors, fonts, and layouts. CSS variables make it easy to customize the theme.

How do I add new features?

Follow the existing code structure and add new HTML sections, CSS styles, and JavaScript functions in the appropriate files.

Is the data persistent?

Data persists during the session but is lost on page refresh. Connect to a backend database for persistent storage.
